# Initial Badges and XP Sources

## Document status

This document is a rough outline of possible badges and XP sources. It is not a final reward catalogue.

The final names, descriptions, artwork, conditions, XP values, limits, repeatability rules, and themed presentation should be decided only if the gamification system moves into implementation.

The working names below may be replaced by conventional LMS terminology or by a stronger theme. The functional earning rules should remain understandable independently of presentation.

## 1. Suggested badges

| Working badge | Awarded for | Notes |
|---|---|---|
| Course Starter | Completing the first required course activity | One per course or course instance according to the final rule |
| Halfway There | Reaching 50% required course progress | Uses a trusted Course Milestone |
| Course Completed | Completing all required course work | Does not require optional 100% |
| Exam Ready | Completing all configured final-exam readiness requirements | Separate from exam attendance |
| Explorer | Completing optional activities or an exploration challenge | Must remain optional |
| Study Group Contributor | Completing a configured Study Group learning goal | No award for membership alone |
| Collaborative Contributor | Meeting the visible minimum individual contribution in a Collaborative Challenge | Separate from group completion |
| Group Challenge Completed | Belonging to a group that completed a Collaborative Challenge, where the rule permits a group-level award | A personal reward may still require individual contribution |
| Knowledge Refreshed | Completing an eligible Post-course Knowledge Refresher | Repeatability and intervals must be limited |
| Knowledge Maintained | Demonstrating a configured retained-knowledge result | Does not alter historical course completion |
| Challenge Winner | Winning or placing highly in an opt-in competitive challenge | Only after results and ties are finalized |

These are examples only. Additional badges may be added later when the implementation scope and available LMS events are confirmed.

## 2. Suggested XP sources

XP may be awarded for:

- completing a required course activity;
- reaching a major required-progress milestone;
- completing an optional exploration activity or challenge;
- completing all required course work;
- completing all optional course activities;
- becoming ready for the final exam;
- attending or completing the final exam, when reliable tracking exists;
- making a verified individual contribution to a Collaborative Challenge;
- completing an eligible individual, group, or opt-in competitive challenge;
- completing a scheduled Post-course Knowledge Refresher;
- demonstrating a configured retained-knowledge result.

Earning a badge may accompany an XP award, but it should not automatically create additional XP when both the badge and XP come from the same source event. This avoids rewarding the same action twice by accident.

## 3. Actions that should not award XP

XP should not be awarded merely for:

- logging in;
- opening a course page, lesson, Study Group, or refresher page;
- remaining online;
- repeatedly viewing or completing the same content;
- creating raw messages or reactions;
- joining or remaining in a Study Group;
- being listed as a member of a completed group challenge without meeting the personal contribution rule;
- starting but not meaningfully completing a refresher where completion is required;
- clicking gamification elements;
- generating duplicate events.

## 4. Deferred decisions

The following details should be decided during product and technical implementation:

- exact XP amounts;
- level thresholds;
- daily, weekly, course-level, challenge-level, or refresher-level XP limits;
- exact badge conditions and repeatability;
- whether badges are private, group-visible, or public;
- correction and revocation rules for each reward;
- final badge names, descriptions, artwork, and theme.
